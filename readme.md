# WeatherMC
![GitHub Release](https://img.shields.io/github/v/release/TheTwoBoom/Betala?include_prereleases&style=for-the-badge&color=black)


WeatherMC is a helpful weather-widget in your Minecraft server-list, that doesn't require any client-side modifications

## Quick Start
Download the latest version from the [Releases](https://github.com/TheTwoBoom/WeatherMC/releases) page\
The JAR file can be executed on any Java 21+ runtime enviroment with the following command:
```
java -jar WeatherMC.jar -Xms256m -Xmx1024m
```

> [!WARNING]
> WeatherMC is currently under **heavy development**.\
> UI and Features will change over time

## Features
- Different weather forecasts all in your server list
- Weather forecasts via OpenWeatherMap API
- Automatic location detection via IP address
